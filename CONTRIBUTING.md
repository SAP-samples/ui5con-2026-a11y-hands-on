# Contributing

## Contributing with a pull request

Please follow the steps below to contribute to this project via pull request:

1. Read and agree to the [Developer Certificate of Origin (DCO)](https://developercertificate.org/). Contributing to this project requires accepting the DCO, which will happen automatically when you create your first pull request.
2. Fork the repository on GitHub.
3. Create a branch for your changes.
4. Commit your changes with a clear message. Sign off each commit with `git commit --signoff` to indicate that you agree to the DCO.
5. Push your branch to your fork.
6. Open a pull request against the `main` branch of this repository.

## Reporting an issue

If you find a bug or want to suggest an improvement, please [create an issue](https://github.com/SAP-samples/ui5con-2026-a11y-hands-on/issues) in this repository.

Before opening a new issue, please search existing issues to see if the topic has already been raised.

## Code of Conduct

All members of the project community must abide by the [Code of Conduct](CODE_OF_CONDUCT.md). Only by respecting each other we can develop a productive, collaborative community. Instances of unacceptable behavior may be reported to the project maintainers or to ospo@sap.com.

## Engaging in Our Project

We use GitHub to handle all source code, planning, and discussions.

Before starting on a substantial contribution, please open an issue describing what you plan to do, so we can align on scope and approach.
